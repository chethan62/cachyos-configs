# CachyOS Configs Backup

Backup of my CachyOS configuration files.

- **fish/** — Fish shell config (CachyOS default)
- **fastfetch/** — System info display
- **kdeglobals** — KDE Plasma settings
- **cachyos-defaults-*.tar.gz** — System CachyOS configs
- **cachyos-skel-*.tar.gz** — Fresh user template
- **sddm-config-*.tar.gz** — SDDM theme config
- **10-session.conf** — Plasma as default session
